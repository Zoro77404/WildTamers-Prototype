# Wild Tamers (Prototype) — Project Memory

- **Unity:** 6000.3.10f1, URP (use URP/Lit materials). Input System only.
- **Game:** Pokémon GO–style, low-poly animals. Fight wild animals in turn-based battles (Attack/Defend/Skill/Run); win = animal joins team.
- **Platform:** PC/Editor prototype, mouse+keyboard. Built for phone portrait (1080x1920, Canvas Scaler Scale With Screen Size, big buttons) later.
- **Art:** low-poly, flat pastel colors, bright and friendly. Quaternius CC0 animals, Fredoka font, procedural city tiles + battle arena, generated UI sprites.
- **Architecture:** `ILocationProvider` (FakeLocationProvider now, GPS later), `MapView` + `MapTileProvider` (fake city now, real tiles later), `AnimalData` ScriptableObjects in `AnimalDatabase`, `GameSession` (DontDestroyOnLoad) holds team, wild spawns, battle hand-off, SceneFader, PreviewStudio (3D animal portraits for UI).
- **Battle:** `BattleController` runs rounds (Defend/Run first, then by speed); `BattleRules` + `BattleAI` are pure math (EditMode tests in `Scripts/Editor/Tests`); `BattleActor`/`BattleHUD`/`BattleResultPanel` are the visuals. All tuning (damage, crit, run, AI, XP, regen) lives in `Resources/GameConfig`.
- **Save:** `SaveSystem` JSON at `persistentDataPath/wildtamers_save.json` (team, levels, XP, HP, active index); autosaves on team changes. Team panel has a 2-tap "Reset save".
- **Code:** `Assets/_Project/Scripts/` — Core, Map, Player, Animals, UI, Battle, Editor (builders under menu Wild Tamers/Build/*).
- **Scenes:** MapScene (index 0), BattleScene (index 1). Both are generated by the builders — change the builder, then rebuild.
- **Roadmap:** PLAN.md — Phases 1–2 done (all planned phases). Don't build "Later" items (GPS, real map, phone build, types, items, gyms, multiplayer).
- **Status:** Phase 2 complete (2026-10-01) — full find → fight → join loop with XP/level-ups and JSON save.
