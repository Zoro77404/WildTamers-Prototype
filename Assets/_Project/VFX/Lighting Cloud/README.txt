LIGHTNING_CLOUD.abc (142 MB) lives in this folder but is not on GitHub: it is over GitHub's 100 MB file limit.
The game does not need it - it plays the baked copy in Assets/_Project/Data/VFX/Baked/LightningCloud.bytes, which is on GitHub.
To change the lightning effect on another PC, copy LIGHTNING_CLOUD.abc here from the PC that has it, then run Wild Tamers > Build > VFX Bakes.
